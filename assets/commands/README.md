# Фотографии команд

Сюда кладутся фотографии настоящих собак для каждой команды.
Как только файл появляется здесь — он автоматически заменяет рисунок в приложении
(на экране «Что уже умеет», в карточках команд и на странице команды).
Если файла нет — показывается нарисованная заглушка. Ничего не ломается.

## Правила

- Формат: **JPG**, имя файла — строго `<id>.jpg` из таблицы ниже.
- Размер: примерно **1200×900 px** (горизонтальные, 4:3), вес до ~300 КБ.
- Стиль: одинаковый у всех (один фон/свет/собака или единый стиль), иначе будет «разнобой».
- Картинка обрезается по центру (object-fit: cover) — собака должна быть в центре кадра.

## Где взять фото

1. **Своя съёмка** — одна собака, один фон, при дневном свете. Самый «живой» вариант.
2. **Сток** (бесплатно для коммерческого использования): unsplash.com, pexels.com.
   Минус: трудно найти все 12 поз в едином стиле.
3. **ИИ-генерация** (быстро и единый стиль) — генератор по одному и тому же описанию
   меняя только позу. Готовые подсказки — в файле `PROMPTS.md` рядом.
